CI/CD en la Nube

Despliegue en GitHub + Firebase Hosting

Este archivo único (index.html) está listo para subirse a un repositorio de GitHub y publicarse automáticamente en la nube con Firebase Hosting:

# 1. Subir el código a tu repositorio GitHub

git init && git add index.html

git commit -m "Sistema de reservas de canchas"

git remote add origin https://github.com/hgarcia69/canchas-app.git

git push -u origin main

# 2. Conectar Firebase Hosting con GitHub Actions

npm install -g firebase-tools

firebase login

firebase init hosting

# Selecciona: "Set up automatic builds and deploys with GitHub"

Además, el sistema calcula automáticamente el identificador de la semana ISO actual (YYYY-Www), por lo que cada lunes abre un registro limpio sin perder la continuidad operativa.
